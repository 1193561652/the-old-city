# The Old City

一款以衰败古城重建与守卫为核心的 UE5 单机游戏。

当前开发只聚焦“执政官守城”最小原型：在约 15 分钟内完成资源生产、城市修复、建造布防与三波守城。长期愿景中的将军指挥、战士 RPG、科技—文化—制度网络均在 MVP 验证后再评估。
