# MVP 范围：执政官守城

更新日期：2026-07-13

## 原型要回答的问题

重建、生产、布防与敌人压力连接起来之后，是否有趣、清楚，并能产生真正的取舍？

## 15 分钟流程

- 0–3 分钟：移动 RTS 相机，观察破损城墙和资源，放置生产建筑。
- 3–7 分钟：积累资源，修复一个城墙缺口，建造兵营和防御塔。
- 7–15 分钟：训练一队守军，调整防线，抵御三波增强的敌人。
- 结束：城心存活则胜利，被摧毁则失败，并可立即重开。

## 必须有

- 一个灰盒地图：破损城墙、城内空地、敌军入口、城心。
- 两种资源。
- 三种基础建筑、一座防御塔。
- 一种守军、两种敌人。
- 三波敌军及明确胜负条件。
- 执政官 RTS 相机、建造与简单调度。

## 明确不做

- 完整城市或开放世界。
- 港口区正式内容。
- 将军 / 战士身份切换与第三人称战斗。
- 外交、文化、制度与随机科研。
- 复杂经济链、装备、任务和遗迹探索。
- 正式美术、剧情配音和大规模内容生产。
- 联机、GAS、程序化世界和未经性能验证的大规模 ECS 架构。

## 验收标准

- 可运行：启动、完整游玩、胜负、重开均无阻塞；Windows 包可运行。
- 可理解：首次试玩者无需讲解，五分钟内完成第一座生产建筑。
- 可决策：至少出现一次“修墙、造塔、出兵”的明确取舍。
- 可迭代：造价、产速、生命值与波次无需修改核心代码即可调整。
- 性能：目标设备 RTX 3080 / 32 GB；灰盒 60 FPS，100 个活动单位内无明显卡顿。

## 当前两周目标

建立第一个可打包灰盒：RTS 相机可移动、缩放、旋转；可选择地面、预览并合法放置一座由数据资产定义的建筑。此阶段不做战斗。
